# Lacuna

An Obsidian plugin for writers. When you don't know a fact while writing, drop a marker, keep going, and resolve it later with sourced answers from Claude.

```
Windows 95 was released on ==?suppl: exact release date==.
```

A *lacuna* is a gap in a manuscript that an editor later fills. Answers are recorded in an `Apparatus/` folder, named after the *apparatus criticus*, the footnotes of a scholarly edition that record sources and alternative readings.

**Status:** under construction. Design and decisions are in [docs/](docs/00-overview.md). The README will be completed at implementation step 7.
