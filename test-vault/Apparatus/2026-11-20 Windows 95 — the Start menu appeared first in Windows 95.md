# the Start menu appeared first in Windows 95

> Context sent to the search:
>
> Windows 95 introduced the Start menu ==?check: the Start menu appeared first in Windows 95== and the taskbar.

## Candidate 1
Windows 95, released in August 1995, was the first Windows version to include the Start menu (together with the taskbar).

- [Windows 95 - Wikipedia](https://en.wikipedia.org/wiki/Windows_95) — “such as the Start menu and the taskbar, originated in Windows 95”

## Candidate 2
Microsoft itself said Windows 95 introduced the Start button and the taskbar.

- [Happy Birthday Windows 95 (Microsoft TechNet / Ask the Directory Services Team)](https://techcommunity.microsoft.com/blog/askds/happy-birthday-windows-95/396897) — “Fourteen years ago today, Windows 95 introduced the world to the Start button and the Taskbar.”
